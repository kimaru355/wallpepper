Install

Android (7.0 or newer)
  1. Download the APK on your phone and open it.
  2. Android will ask to allow installs from your browser (or Files app): allow it for this one install.
  3. Tap Install. If Play Protect shows a warning for an app it hasn’t seen, choose Install anyway — the app is signed with our release key.
  4. Open Wallpepper, then allow photo saving the first time you download a wallpaper.

Automatic wallpaper switching runs in the background. If your phone maker stops background apps, exclude Wallpepper from battery optimisation.

Windows (10 / 11, 64-bit)
  1. Run Wallpepper-Setup.
  2. Windows SmartScreen may say “Windows protected your PC” because the installer is unsigned: click More info → Run anyway.
  3. Wallpepper lives in the system tray, so scheduled wallpaper changes keep running when the window is closed.
Linux (x86-64)

AppImage (any distro):

chmod +x Wallpepper-*.AppImage
./Wallpepper-*.AppImage

.deb (Debian, Ubuntu, Mint…):

sudo apt install ./Wallpepper-*-linux-amd64.deb

Wallpaper setting supports GNOME, Cinnamon, MATE, KDE Plasma, XFCE, sway, or feh/nitrogen. On other desktops use “Download to folder” mode.

Accounts & sync

Create a free account inside the app (Account & Devices) and sign in on your other devices. Wallpepper syncs your saved wallpaper links, groups, custom sources and each device’s settings.

  • Images themselves are never uploaded — only the links to them.
  • Source API keys (for example TMDB) stay on the device and are not synced.
  • You can delete your account and everything synced to it at any time.
  • Everything works without an account too; sign in whenever you want sync.
